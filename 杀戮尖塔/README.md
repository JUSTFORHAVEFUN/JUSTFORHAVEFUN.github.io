# 杀戮尖塔 · 网页复刻版 (Slay the Spire Web)

纯前端实现的《杀戮尖塔》复刻版，**双击 `index.html` 即可开始游戏**，无需服务器、无需构建、无需联网。

---

## 快速开始

```
直接双击打开  C:\Stshtml\index.html
```

如果想用本地服务器（可选）：

```powershell
cd C:\Stshtml
python -m http.server 8080     # 或 npx serve .
# 浏览器访问 http://127.0.0.1:8080
```

---

## 操作方式

| 操作 | 说明 |
|---|---|
| **拖动卡牌** | 向上拖出手牌打出；需要指定目标的牌拖到敌人身上（会显示绿色瞄准箭头） |
| **单击卡牌** | 无目标牌直接打出；需要目标的牌先点牌、再点敌人 |
| **空格** | 结束回合 |
| **1–9** | 快速打出对应位置的手牌 |
| **E** | 查看牌组 |
| **Esc** | 关闭弹窗 |
| 点击抽牌堆/弃牌堆/消耗堆 | 查看堆中卡牌 |
| 点击顶栏药水槽 | 使用或丢弃药水 |
| 悬停遗物 / Buff / 关键词 | 显示详细说明 |

## 已实现的内容

### 战斗引擎
- 能量、格挡、抽牌堆 / 手牌 / 弃牌堆 / 消耗堆，10 张手牌上限、洗牌重构

- 卡面数值**实时预览**：受力量/敏捷/虚弱/脆弱影响的数字会变绿或变红
- 70+ 种能力（Buff/Debuff）：易伤、虚弱、脆弱、力量、敏捷、中毒、神器、荆棘、金属化、镀层、再生、壁垒、无形、缓冲、腐化、进化、喷火、黑暗拥抱、感觉不到痛、势不可挡、恶魔之型、残暴、狂暴、自燃、破裂、混乱、华丽、剧毒、毒气、精准、残影、无限之刃、千刀万剐、幽灵形态、回响形态……以及敌人专属的仪式、卷曲、激怒、孢子云、刺痛之伤、锋利外皮、可塑、模式切换、死亡节拍、无敌、时间扭曲、好奇心、未觉醒、飞行、自爆、生命链接、变形等

- **第三幕**：暗影兽、法球行者、尖刺者、爆破者、排斥者、蠕动之物、巨口、短暂之物；精英：巨大头颅、复仇女神、蜥蜴法师（召唤匕首蛇）；首领：觉醒者（复活二阶段）、时间吞噬者（12 张牌强制结束回合）、德卡与多努
- **第四幕**：尖塔之盾 + 尖塔之矛、腐化之心（无敌 300 / 死亡节拍 / 逐层强化）

原作的敌人行动权重与「同一动作不可连续 N 次」限制都已还原，并按进化等级调整数值。

### 流程与房间
- 15 层分支地图（6 条路径、第 9 层固定宝箱、末层固定营火、精英/营火不出现在前 5 层、同路径不连续同类特殊房间）
- 房间类型：普通战斗 / 精英 / 首领 / 未知 / 营火 / 商店 / 宝箱
- **尼奥的祝福**开局四选一（含带代价的高风险选项）
- **41 个事件**：大鱼、神职者、死去的冒险者（风险递增）、金色雕像陷阱、活墙、巨大蘑菇、废料软泥、闪光、黏液世界、篝火精灵、诅咒之书、被遗忘的祭坛、图书馆、吸血鬼、幽灵议会、心灵绽放、命运之轮、秘密传送门、各类神龛……
- **商店**：5 张角色牌 + 2 张无色牌 + 3 件遗物 + 3 瓶药水 + 移除卡牌服务，价格随稀有度浮动，会员卡/信使打折
- **营火**：休息 / 锻造，并支持举重壶铃、铲子、和平烟斗、捕梦网、豪华枕头、永恒之羽等遗物额外选项
- 战斗奖励：金币、卡牌（3 选 1，含稀有度权重与跨幕升级概率）、药水、精英遗物、首领遗物三选一
- 进化等级 0–20（更高生命的敌人、开局伤害、登顶者之殇诅咒等）
- 自动存档（localStorage），标题界面「继续游戏」可恢复整局进度与地图
- **局域网 PvP**：运行 `python3 server.py` 后，两名玩家各自选 30 张牌、100 血实时对战
- **反制**：战斗中选择隐藏反制牌；PvE 按敌方意图触发，PvP 按对手下回合出的牌类型触发，对手看不到你布置了哪张

## 开发与测试

```powershell
# 语法检查
Get-ChildItem -Recurse -Filter *.js | ForEach-Object { node --check $_.FullName }

# 无头模拟器：自动跑局，捕获运行时异常并统计每场战斗的平均掉血
node tools\sim.js 12            # 随机 AI 跑 12 局
node tools\sim.js 12 smart      # 启发式 AI（受威胁时优先防御）
node tools\sim.js 4 god         # 无敌模式，用于跑通全部四幕与所有首领
```

浏览器调试参数（附加在 URL 后）：

| 参数 | 作用 |
|---|---|
| `?auto=1` | 直接开局 |
| `?auto=1&combat=1` | 开局并进入第一场战斗 |
| `?auto=1&combat=1&play=1` | 再自动打完这场战斗 |
| `&char=silent` | 指定角色 |
| `&geom=1` | 把关键元素的布局坐标写入 `body[data-geom]`（排查布局） |

脚本错误会写入 `body[data-jserr]` 并在界面上以提示条显示。

## 与原作的差异

- 美术使用 CSS 渐变 + Emoji 表意，没有原作的手绘立绘与音乐音效
- 只实现了铁甲战士与静默猎手两位角色（缺陷机器人与观者尚未加入）
- 部分冷门事件/遗物做了合理近似（例如尼尔莉的书、天球仪、星盘等的交互被简化）
- 进化等级只实现了影响较大的若干档（2 / 6 / 7 / 9 / 10 / 14 / 17 / 18 / 19）
- 未实现钥匙收集，第四幕通过击败第三幕首领后的选项直接进入
